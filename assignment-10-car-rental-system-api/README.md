# 🚗 Assignment 10: Car Rental & Fleet Booking System with Supabase
> **Track:** Backend Development | **Level:** Intermediate | **Estimated Time:** 6–8 Hours  
> **Tech Stack:** Node.js, Express.js, Supabase (PostgreSQL Cloud DB & Auth), dotenv, cors

---

## 📌 1. Objective & Overview

Build a production-ready **Car Rental & Vehicle Fleet Management API** utilizing **Supabase** (PostgreSQL & Auth). Students will implement complex date-range overlap validations to prevent vehicle double-booking, automatic rental price calculations based on day spans, relational joins between cars and reservation histories, and secure data access using Supabase JWT tokens.

### Key Learning Outcomes:
- Designing relational PostgreSQL schemas in Supabase with foreign keys, constraints, and timestamps.
- Implementing date collision checks in SQL / Supabase JavaScript SDK.
- Calculating dynamic billing totals (`days * daily_rate`) on the backend server.
- Managing vehicle fleet availability state transitions (`available` ➔ `rented` ➔ `maintenance`).
- Authenticating users and protecting customer booking histories using Supabase Auth.

## 🗄️ 3. Supabase Database Schema (SQL)

Execute this script in your **Supabase SQL Editor**:

```sql
-- 1. Vehicles Table
CREATE TABLE vehicles (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    brand TEXT NOT NULL,
    model TEXT NOT NULL,
    year INT NOT NULL,
    category TEXT NOT NULL CHECK (category IN ('Sedan', 'SUV', 'Luxury', 'Hatchback', 'Electric')),
    daily_rate NUMERIC(10, 2) NOT NULL CHECK (daily_rate > 0),
    fuel_type TEXT NOT NULL,
    seating_capacity INT NOT NULL DEFAULT 5,
    status TEXT NOT NULL DEFAULT 'available' CHECK (status IN ('available', 'rented', 'maintenance')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Rentals / Bookings Table
CREATE TABLE rentals (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID NOT NULL, -- references Supabase auth.users
    vehicle_id BIGINT REFERENCES vehicles(id) ON DELETE RESTRICT,
    customer_name TEXT NOT NULL,
    customer_email TEXT NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE NOT NULL,
    total_cost NUMERIC(10, 2) NOT NULL,
    status TEXT NOT NULL DEFAULT 'booked' CHECK (status IN ('booked', 'active', 'completed', 'cancelled')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT valid_date_range CHECK (end_date >= start_date)
);
```

## 📋 4. API Endpoints Specification

### 🔐 Supabase Auth Endpoints

| Method | Endpoint | Description | Request Body Example | Status Codes |
|---|---|---|---|---|
| `POST` | `/api/auth/register` | Register customer with Supabase | `{"email":"driver@travel.com","password":"mypassword123","name":"David"}` | `201 Created`<br>`400 Bad Request` |
| `POST` | `/api/auth/login` | Login and receive Supabase access token | `{"email":"driver@travel.com","password":"mypassword123"}` | `200 OK`<br>`401 Unauthorized` |

### 🚗 Vehicle Fleet Management

| Method | Endpoint | Auth Required | Description | Request Body Example | Status Codes |
|---|---|:---:|---|---|---|
| `GET` | `/api/vehicles` | No | Fetch all vehicles (supports `?category=SUV&status=available`) | None | `200 OK` |
| `GET` | `/api/vehicles/:id` | No | Get vehicle details with past rental records | None | `200 OK`<br>`404 Not Found` |
| `POST` | `/api/vehicles` | **Yes** | Add new vehicle to fleet (Admin) | `{"brand":"Tesla","model":"Model 3","year":2024,"category":"Electric","daily_rate":4500,"fuel_type":"EV","seating_capacity":5}` | `201 Created`<br>`400 Bad Request` |
| `PUT` | `/api/vehicles/:id` | **Yes** | Update vehicle daily rate or status | `{"daily_rate":4800,"status":"maintenance"}` | `200 OK`<br>`404 Not Found` |
| `DELETE` | `/api/vehicles/:id` | **Yes** | Delete vehicle from fleet | None | `200 OK`<br>`400 Has Active Bookings` |

### 📅 Rental & Booking Operations

| Method | Endpoint | Auth Required | Description | Request Body Example | Status Codes |
|---|---|:---:|---|---|---|
| `POST` | `/api/rentals` | **Yes** | Book a vehicle (Checks date collisions & computes total cost) | `{"vehicle_id":1,"start_date":"2026-05-01","end_date":"2026-05-05","customer_name":"David","customer_email":"david@test.com"}` | `201 Created`<br>`400 Collision/Error` |
| `GET` | `/api/rentals/my-bookings` | **Yes** | List rentals for authenticated user | None | `200 OK` |
| `PATCH` | `/api/rentals/:id/cancel` | **Yes** | Cancel upcoming rental | None | `200 OK`<br>`400 Cannot Cancel` |
| `PATCH` | `/api/rentals/:id/complete`| **Yes** | Mark car as returned (Sets vehicle status back to `available`) | None | `200 OK` |
